# Human Board V0.9 — 최초 전체 흐름 리허설

2026-10-27. 이전 V0.8 구성과 호환.

## 추가한 것
- `mission_e2e_v09.py`: 제안 검증 → 사람 승인 플래그 → 모의 게시 → 모의 수락 → 가상 증빙 제출 → 모의 검수 → 원 임무에 관찰 결과 반환.
- `test_mission_e2e_v09.py`: 정상 흐름/차단/증빙 미검증/무결제 여부 확인.
- `e2e_v09_results.json`: 실행 기록.

## 실행
```bash
cd human_board
python -m unittest discover -p 'test_*.py' -q
python mission_e2e_v09.py
python server.py
```

## 반드시 구분
- **실제 AI 모델의 자율적 도구 선택: 미검증** (외부 모델 인증 정보 없음).
- **현장 작업: 0건**, **결제: 0원**. 작업자/증빙/승인은 모두 가상.
- 정상 흐름도 근거가 있는 현장 사실이 아닌 **모의 리허설**이며 AI가 원래 업무에 사용하는 기록은 `ground_truth_confirmed=false`로 전달.
- 서버의 `human_authorized` 플래그는 실사용 인증수단이 아니며 누구든 값만 보낼 수 있다. **인터넷 공개 금지**; 실제 적용 전 신원 인증, API 키/권한, 승인 서명, 속도 제한, 개인정보 보호, 예산 집행 통제 필요.

## 다음 결정 관문
실제 모델에게 같은 임무/도구를 제공해 자발적 호출률과 불필요 발주율을 측정한다. 이후 허가받은 장소에서 실제 사람 1건 테스트. 규칙 기반 데이터가 이를 대신하지 않는다.
