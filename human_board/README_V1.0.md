# HUMAN BOARD — V1.0 검증 관문
2026-10-27 | PM 내부 보고

## 이번 변경
`agent_live_gate_v10.py`는 기존 AI 함수 규격(`request_human_fieldwork`)을 Responses API에 **읽기 전용 선택 도구**로 노출합니다. 실 모델이 작업을 제안하는지, 제안하지 않는지 그대로 기록합니다. 호출은 곧바로 작업 게시/고용/지급으로 이어지지 않습니다.

- JSON 파싱/도구 호출 0회·1회 판정, 복수 호출 거부
- 제안의 작업·예산·위험 규칙 검증(기존 V0.8 계약 재활용)
- 입력 시나리오 SHA-256, 결과/오류, 모델 응답 ID 및 실행 형태 기록
- 네트워크 오류 시 규칙 기반 결과로 몰래 대체하지 않음
- 임의 테스트 전송기(injected transport) 검증은 **실제 모델 호출이 아님**을 보고서에 표시

## 실행법
```
cd human_board
python -m unittest discover -p 'test_*.py' -q
python agent_live_gate_v10.py --check
# 실제 모델 계정/요금 설정 및 API 키를 본인 환경에 넣은 뒤에만:
OPENAI_API_KEY=... python agent_live_gate_v10.py --model <사용가능한_모델명> --output live_result.json
```
API 키를 채팅에 보내지 마세요. 본인의 로컬 환경 변수/비밀관리자로 설정하세요. 모델 및 가격/권한은 실제 계정에서 별도 확인합니다. 실 호출에는 과금 가능성이 있습니다.

## 검증 현황
- 로컬 자동 테스트: 31/31 통과 (신규 6개 포함)
- 외부 AI 모델이 자발적으로 도구를 선택하는지: **미실행·미검증**
- 현장 작업자: 0명, 실제 발주: 0건, 실제 지급: 0원
- 사용한 시나리오: 합성 데이터. 한국 정부/지자체 시스템과 실제 연동한 적 없음
